# Cal — Aesthetic Calculator

A fast, responsive calculator inspired by the clean, animated feel of modern aesthetic calculator UIs.

## Features

- Glass-style responsive interface
- Basic arithmetic: `+`, `−`, `×`, `÷`
- Percent and sign controls
- Backspace, clear, decimal input
- Full keyboard support
- Light/dark theme toggle with saved preference
- No backend or build step — works as a static GitHub Pages site

## GitHub Pages

The site is deployed automatically from `main` using GitHub Actions.

Live site: https://TEJAS-MK2.github.io/Cal/

## Credits

The visual direction was inspired by the public **Aesthetic Calculator** project by sandudul. This implementation is independently written for GitHub Pages and does not require Flask or Bootstrap.
